## 🚀 Featured Projects

<details>
<summary><b>01 Smart Ticket Router — AI‑Powered CX Automation</b></summary>

**Problem**  
Support teams manually triaged and routed every inbound ticket — slow, inconsistent, and unscalable beyond ~200 tickets/day.

**Solution**  
Self‑hosted n8n workflow integrated with HubSpot Service Hub that classifies tickets by intent (billing, technical, account), assigns priority, and routes to the correct queue. Includes fallback logic and escalation triggers for SLA breaches.

**Results**  
- Manual triage ↓ **85%**  
- Routing accuracy **92%**  
- First Response Time ↓ ~40% (queue‑time elimination)  

**Stack:** `n8n` · `HubSpot Service Hub` · `Webhooks` · `REST APIs`

</details>

<details>
<summary><b>02 Multi‑Carrier Tracking Ops Dashboard</b></summary>

**Problem**  
Operations had no unified view across carriers (Bosta, Aramex, Egypt Post). Delayed shipments surfaced only after customer complaints (WISMO tickets).

**Solution**  
React + TypeScript + Tailwind dashboard providing unified shipment tracking, delay detection, proactive alerts, n8n workflow health, and manual override controls.

**Results (Modeled)**  
- WISMO reduction: **60%+**  
- Proactive alert coverage: target **95%**  
- Ops response time: target **<15 min** for flagged shipments  

*Built on mock carrier data to demonstrate architecture & UX; metrics modeled on real high‑volume logistics environments.*  

**Stack:** `React` · `TypeScript` · `Tailwind CSS` · `n8n` · `REST APIs`

</details>

<details>
<summary><b>03 VIP Priority Workflow (HubSpot Service Hub)</b></summary>

**Problem**  
Enterprise (VIP) accounts received identical treatment to all other tickets — no priority escalation, proactive outreach, or SLA differentiation.

**Solution**  
HubSpot Service Hub workflow using a custom “Plan Tier” property to auto‑identify VIP accounts. Triggers high‑priority task creation for senior reps and stages a standardized proactive email template (human‑approved send for quality control).

**Results**  
- Automatic priority routing for VIP accounts  
- Proactive outreach activated **without Marketing Hub**  
- Consistent SLA differentiation even on **Free tier**  

**Stack:** `HubSpot Service Hub (Free)` · `Workflows` · `Custom Properties` · `Email Templates`

</details>

<details>
<summary><b>04 Omnichannel Architecture (Black Friday Scale)</b></summary>

Need to handle **5,000+ tickets/day** across WhatsApp, Instagram, Email & Live Chat without adding headcount.

**Solution**  
Designed a horizontally scalable omnichannel routing architecture using n8n as the central orchestration layer, with intelligent queue management and real‑time monitoring.

**Results**
