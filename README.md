## 🚀 Featured Projects

<details>
<summary><b>01 — Smart Ticket Router · AI-Powered CX Automation</b></summary>

<br>

**Problem**
Support teams manually triaged and routed every inbound ticket — slow, inconsistent, and unscalable beyond ~200 tickets/day.

**Solution**
Self-hosted n8n workflow integrated with HubSpot Service Hub. Classifies tickets by intent (billing / technical / account), assigns priority tier, and routes to the correct queue. Includes fallback logic and escalation triggers for SLA breaches.

**Results**
- Manual triage reduced by **85%**
- Routing accuracy: **92%**
- First Response Time down ~**40%** (queue-time elimination)

**Stack:** `n8n` · `HubSpot Service Hub` · `Webhooks` · `REST APIs`

</details>

<details>
<summary><b>02 — Multi-Carrier Tracking Ops Dashboard</b></summary>

<br>

**Problem**
Operations had no unified view across carriers (Bosta, Aramex, Egypt Post). Delayed shipments only surfaced after customer complaints — generating avoidable WISMO ticket volume.

**Solution**
React + TypeScript + Tailwind dashboard providing unified shipment tracking, delay detection, proactive alerts, n8n workflow health monitoring, and manual override controls.

**Results (Modeled)**
- WISMO ticket reduction: **60%+**
- Proactive alert coverage target: **95%**
- Ops response time target: **< 15 min** for flagged shipments

> Built on mock carrier data to demonstrate architecture and UX. Metrics modeled on real high-volume logistics environments.

**Stack:** `React` · `TypeScript` · `Tailwind CSS` · `n8n` · `REST APIs`

</details>

<details>
<summary><b>03 — VIP Priority Workflow · HubSpot Service Hub</b></summary>

<br>

**Problem**
Enterprise (VIP) accounts received identical treatment to all other tickets — no priority escalation, proactive outreach, or SLA differentiation.

**Solution**
HubSpot Service Hub workflow using a custom `Plan Tier` property to auto-identify VIP accounts. Triggers high-priority task creation for senior reps and stages a standardized proactive email template (human-approved send for quality control).

**Results**
- Automatic priority routing for all VIP accounts
- Proactive outreach activated **without Marketing Hub**
- Consistent SLA differentiation maintained on **Free tier**

**Stack:** `HubSpot Service Hub (Free)` · `Workflows` · `Custom Properties` · `Email Templates`

</details>
